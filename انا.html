📝 الخطوات التفصيلية

1

الدخول إلى القائمة الجانبية

من الصفحة الرئيسية:

  • الضغط على أيقونة Hamburger Menu أعلى اليسار
  • فتح القائمة الجانبية الخاصة بالنظام
المسار: Service Delivery Processing → Order Tracking
2

فتح شاشة Order Tracking

بعد اختيار Order Tracking تظهر شاشة البحث عن الطلبات. الشاشة تحتوي على حقول الفلترة والبحث:

الحقل الوصف
Department القسم (Radiology)
MR No رقم الملف الطبي
Patient ID رقم المريض
Patient Name اسم المريض
Date Range نطاق التاريخ
Status حالة الطلب
Attendance نوع المريض
Pharmacy Category التصنيف
3

البحث عن طلب مريض

الخطوات:

  • إدخال رقم المريض أو رقم الملف
  • الضغط على زر: Query Orders
ℹ️

النظام يقوم بجلب جميع الطلبات المرتبطة بالمريض

4

ظهور بيانات الطلب

بعد البحث يظهر جدول الطلبات. البيانات الظاهرة داخل الجدول:

الحقل المعنى
Status حالة الطلب
Urgency درجة الاستعجال
MR No رقم الملف
Patient ID رقم المريض
Location القسم/الموقع
Patient Name اسم المريض
Age العمر
Item الخدمة المطلوبة
Order Datetime وقت إنشاء الطلب
1st Dose Datetime وقت التنفيذ الأول
5

أيقونات التحكم بالطلب

يوجد أيقونتان مهمتان:

ℹ️
أ) أيقونة تفاصيل الطلب

أيقونة المعلومات (i)

وظيفتها:

  • فتح نافذة تفاصيل الطلب
  • المعلومات الظاهرة:
Doctor Patient Location Creation Date Modify Date Created By Modified By Notes Reason For Order Conditions
🖨️
ب) أيقونة الطباعة

أيقونة الطابعة

وظيفتها: فتح ملف PDF للوصفة/طلب الأشعة

6

محتويات نموذج الطباعة (PDF)

النموذج يحتوي على:

البيانات الوصف
Sequence No الرقم التسلسلي
Master Order No رقم الطلب الرئيسي
Request Unit الجهة الطالبة
Patient ID رقم المريض
MR No رقم الملف
Name اسم المريض
Age / Sex العمر والجنس
Order Date تاريخ الطلب
Item Ordered الخدمة المطلوبة
Clinical Notes الملاحظات الطبية
Total Price السعر
Doctor Signature توقيع الطبيب

MR No Patient ID Patient Name Age Gender
